# 🛡️ KavachGrid AI

### Autonomous Cold-Chain & Zero-Trust Telemetry Engine

KavachGrid AI is a security-focused prototype designed to demonstrate intelligent cold-chain monitoring, telemetry risk analysis, and simulated autonomous decision-making for sensitive medical supplies and perishable food.

🌐 **Live Demo:** https://ompkshirsagar168.github.io/prompt-war-2026/

## 🚀 Features

- **Live Operations Dashboard:** Monitor simulated cold-chain telemetry.
- **Risk Analysis:** Estimate risk using temperature, ambient conditions, and delivery delay.
- **Telemetry Fingerprinting:** Generate SHA-256 hashes for payload integrity demonstrations.
- **Security Attack Simulation:** Demonstrate simulated spoofing and injection attack scenarios.
- **Autonomous Agent Simulation:** Display simulated analysis and decision logs.
- **Data Export:** Export telemetry and simulation data as JSON.
- **Google Cloud Concepts:** Demonstrate example architecture and BigQuery SQL for future integration.

## 🧰 Technology Stack

- HTML
- Tailwind CSS
- JavaScript
- Chart.js
- Web Crypto API (SHA-256)
- Google Cloud integration concepts

## 🏁 Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Explore the dashboard, adjust telemetry values, and test the security simulation.
4. Export the generated demo data as JSON.

## 🔐 Security Notes

This project is a prototype and demonstration, not a production-ready security system.

- SHA-256 hashing alone does not authenticate a device or prove that telemetry is trustworthy.
- Attack detection and autonomous decisions shown in the browser are simulations unless backed by a verified server-side implementation.
- Production deployment requires server-side telemetry validation, authenticated devices, replay protection, secure API-key management, and appropriate access controls.
- Never publish API keys or other secrets in client-side code or a public repository.
